# 🩸 Veda Hospital Blood Bank Management System

A full-stack Blood Bank Management System developed for managing blood donors, registrations, authentication, and blood-related services.

## 🏥 Hospital

**Veda Hospital & Blood Care Center**  
📍 C24, Vasant Vihar, Ujjain, Madhya Pradesh

## 🚀 Features

- 🩸 Donor Registration
- 🔐 Secure Login & Authentication
- 🔑 Password Hashing using bcrypt
- 🎫 JWT Authentication
- 👤 Donor Management
- 🗄️ MongoDB Database
- 📧 Email Notification on Registration
- 🔎 Blood Group Management
- 📱 Responsive Frontend
- ⚡ REST API
- 🌐 Full-Stack Architecture
